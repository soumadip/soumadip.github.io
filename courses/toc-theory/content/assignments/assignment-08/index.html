Section A: True or False Questions

For each question, select True or False and provide a rigorous mathematical justification.

Question 1

If a Context-Free Grammar \(G = (V, T, S, P)\) is in Chomsky Normal Form (CNF), then for any non-empty string \(w \in L(G)\) of length \(n = |w| \ge 1\), every derivation of \(w\) in \(G\) takes exactly \(2n - 1\) steps.

💡 View Solution

Answer: True

Justification: In Chomsky Normal Form (CNF), all production rules are strictly of the form \(A \to BC\) (variable-branching) or \(A \to a\) (terminal substitution).

  • To derive a string of length \(n\) starting from a single start variable \(S\), the derivation tree must expand from 1 variable leaf to \(n\) variable leaves. Each application of a binary production \(A \to BC\) increases the number of variable leaves by exactly 1. Therefore, exactly \(n - 1\) binary steps of the form \(A \to BC\) are required to generate \(n\) variables.
  • Once \(n\) variables are present, each variable must be converted into a terminal symbol using a rule of the form \(A \to a\). This requires exactly \(n\) terminal substitution steps.
  • The total number of derivation steps is therefore: \[(n - 1) + n = 2n - 1\] This exact step count holds universally for every derivation of length \(n\) in any CNF grammar.

Question 2

The family of Context-Free Languages (CFLs) is closed under intersection, meaning that if \(L_1\) and \(L_2\) are context-free, then \(L_1 \cap L_2\) is guaranteed to be context-free.

💡 View Solution

Answer: False

Justification: Context-Free Languages are NOT closed under intersection. We prove this by counterexample using two known context-free languages:

  • Let \(L_1 = {a^n b^n c^m \mid n, m \ge 0}\) (generated by \(S \to AB, A \to aAb \mid \lambda, B \to cB \mid \lambda\)). \(L_1\) is a CFL.
  • Let \(L_2 = {a^m b^n c^n \mid m, n \ge 0}\) (generated by \(S \to AB, A \to aA \mid \lambda, B \to bBc \mid \lambda\)). \(L_2\) is a CFL.
  • The intersection of \(L_1\) and \(L_2\) enforces both conditions simultaneously: \[L_1 \cap L_2 = {a^n b^n c^n \mid n \ge 0}\] As proven via the CFL Pumping Lemma, \({a^n b^n c^n \mid n \ge 0}\) is not a Context-Free Language. Thus, CFLs are not closed under intersection.

Question 3

If \(L\) is a Context-Free Language over \(\Sigma\) and \(R\) is a Regular Language over \(\Sigma\), then the intersection \(L \cap R\) is guaranteed to be a Context-Free Language.

💡 View Solution

Answer: True

Justification: CFLs are closed under intersection with regular languages (Linz Theorem 8.5, Sipser Problem 2.18).

  • Proof Construction: Let \(M_1 = (Q_1, \Sigma, \Gamma, \delta_1, q_0, z_0, F_1)\) be a Pushdown Automaton (PDA) recognizing \(L\), and let \(M_2 = (Q_2, \Sigma, \delta_2, p_0, F_2)\) be a Deterministic Finite Automaton (DFA) recognizing \(R\).
  • We construct a product PDA \(M = (Q_1 \times Q_2, \Sigma, \Gamma, \delta, (q_0, p_0), z_0, F_1 \times F_2)\) that simulates \(M_1\) and \(M_2\) in parallel: \[\delta((q, p), a, X) = { ((q’, p’), \gamma) \mid (q’, \gamma) \in \delta_1(q, a, X) \text{ and } p’ = \delta_2(p, a) }\] For \(\lambda\)-transitions of the PDA, the DFA state remains unchanged: \[\delta((q, p), \lambda, X) = { ((q’, p), \gamma) \mid (q’, \gamma) \in \delta_1(q, \lambda, X) }\]
  • Since \(M\) tracks the stack operations of \(M_1\) while simultaneously verifying state transitions of \(M_2\) in its finite control, \(M\) is a valid PDA that accepts \(w\) if and only if \(w \in L\) and \(w \in R\). Thus, \(L \cap R\) is a CFL.

Question 4

In the CFL Pumping Lemma (\(w = uvxyz\)), the bounded condition \(|vxy| \le m\) implies that the pumpable substring \(vxy\) must always reside within the first \(m\) characters at the beginning of the string \(w\).

💡 View Solution

Answer: False

Justification: Unlike the Regular Pumping Lemma (where \(|xy| \le p\) forces \(xy\) to occur within the initial \(p\) characters of the string), the condition \(|vxy| \le m\) in the CFL Pumping Lemma specifies that the length of the central substring \(vxy\) cannot exceed \(m\), but \(vxy\) can occur anywhere within the string \(w\). It is not restricted to the prefix of \(w\).

Question 5

Which of the following operations preserve context-freeness (i.e., Context-Free Languages are closed under these operations)? (Select all that apply)

  • Options:
    • A) Union (\(L_1 \cup L_2\))
    • B) Concatenation (\(L_1 \cdot L_2\))
    • C) Kleene Star (\(L^*\))
    • D) Complementation (\(\bar{L} = \Sigma^* - L\))
💡 View Solution

Correct Options: A, B, C

Justification:

  • A is correct: Given CFGs \(G_1 = (V_1, T_1, S_1, P_1)\) and \(G_2 = (V_2, T_2, S_2, P_2)\) with disjoint variable sets, we construct \(G_{union}\) with start variable \(S \to S_1 \mid S_2\). Thus, CFLs are closed under union.
  • B is correct: We construct \(G_{concat}\) with start variable \(S \to S_1 S_2\). Thus, CFLs are closed under concatenation.
  • C is correct: We construct \(G_{star}\) with start variable \(S \to S S_1 \mid \lambda\). Thus, CFLs are closed under Kleene star.
  • D is incorrect: CFLs are not closed under complementation. By De Morgan’s Laws, \(L_1 \cap L_2 = \overline{\overline{L_1} \cup \overline{L_2}}\). If CFLs were closed under complementation, they would also be closed under intersection (since they are closed under union), which contradicts Question 2.

Question 6

Consider the grammar simplification pipeline and normal form transformations. Which of the following statements are correct? (Select all that apply)

  • Options:
    • A) A variable \(A\) is called nullable if there exists a derivation \(A \Rightarrow^* \lambda\).
    • B) In Greibach Normal Form (GNF), every production rule is of the form \(A \to a\alpha\), where \(a \in T\) and \(\alpha \in V^*\).
    • C) When converting a CFG to Chomsky Normal Form (CNF), \(\lambda\)-productions and unit productions (\(A \to B\)) must be eliminated before replacing terminal mixtures or breaking long variable chains.
    • D) A variable \(A\) is defined as useful if it is both generating (\(A \Rightarrow^* w \in T^\)) and reachable (\(S \Rightarrow^ xAy\)).
💡 View Solution

Correct Options: A, B, C, D

Justification:

  • A is correct: This is the precise definition of a nullable variable used when eliminating \(\lambda\)-productions.
  • B is correct: By definition of GNF, every rule starts with exactly one terminal symbol \(a\), followed by zero or more variables \(\alpha\). This guarantees that a PDA reading a GNF grammar consumes exactly one terminal input symbol per stack step, eliminating infinite \(\lambda\)-loops.
  • C is correct: The standard CNF conversion pipeline requires:
    1. Eliminate \(\lambda\)-productions.
    2. Eliminate unit productions (\(A \to B\)).
    3. Eliminate non-generating and unreachable variables.
    4. Replace mixed terminal rules (e.g., \(A \to aB \implies A \to V_a B, V_a \to a\)).
    5. Break long variable chains (\(A \to B C D \implies A \to B V_1, V_1 \to C D\)). Reversing this order can re-introduce unit productions or broken rule forms.
  • D is correct: Linz Section 6.1 defines a variable \(A\) as useful if and only if \(A\) can participate in at least one valid derivation of a terminal string from the start symbol \(S\) (\(S \Rightarrow^* xAy \Rightarrow^* xwy \in T^*\)).

Question 7 (Grammar Simplification & CNF Conversion)

Simplify the following context-free grammar \(G\) by eliminating useless variables, \(\lambda\)-productions, and unit productions, and then convert the resulting grammar into Chomsky Normal Form (CNF):

\[S \to aA \mid B \mid \lambda\] \[A \to aA \mid \lambda\] \[B \to bB \mid C\] \[C \to c\]

💡 View Solution

Step 1: Identify and Eliminate Non-Generating & Unreachable Variables

  1. Generating variables:
    • \(C \to c \implies C\) is generating.
    • \(A \to \lambda, S \to \lambda \implies A, S\) are generating.
    • \(B \to C \implies B\) is generating. All variables \({S, A, B, C}\) are generating.
  2. Reachable variables (from \(S\)):
    • \(S\) reaches \(A\) (via \(S \to aA\)) and \(B\) (via \(S \to B\)).
    • \(B\) reaches \(C\) (via \(B \to C\)). All variables are reachable.

Step 2: Eliminate \(\lambda\)-Productions

  1. Find all nullable variables:
    • \(A \to \lambda \implies A\) is nullable.
    • \(S \to \lambda \implies S\) is nullable.
  2. Re-write rules excluding \(\lambda\) (accounting for nullable options):
    • For \(S \to aA\): \(A\) can be dropped \(\implies S \to aA \mid a\).
    • For \(A \to aA\): \(A\) can be dropped \(\implies A \to aA \mid a\).
    • For \(S \to B\): \(B\) is not nullable \(\implies S \to B\).
    • For \(B \to bB \mid C\) and \(C \to c\): unchanged.

Grammar without \(\lambda\)-productions (for \(L(G) - {\lambda}\)): \[S \to aA \mid a \mid B\] \[A \to aA \mid a\] \[B \to bB \mid C\] \[C \to c\]

Step 3: Eliminate Unit Productions

Find all unit pairs \((X, Y)\) where \(X \Rightarrow^* Y\):

  • From \(S\): \((S, S), (S, B), (S, C)\) (since \(S \to B\) and \(B \to C\)).
  • From \(B\): \((B, B), (B, C)\) (since \(B \to C\)).
  • From \(A\): \((A, A)\).
  • From \(C\): \((C, C)\).

Replace unit transitions with direct non-unit productions:

  • For \((S, B)\): add \(B\)’s non-unit rules \(\implies bB\).
  • For \((S, C)\): add \(C\)’s non-unit rules \(\implies c\).
  • For \((B, C)\): add \(C\)’s non-unit rules \(\implies c\).

Grammar without unit productions: \[S \to aA \mid a \mid bB \mid c\] \[A \to aA \mid a\] \[B \to bB \mid c\] \[C \to c\]

Step 4: Convert to Chomsky Normal Form (CNF)

  1. Introduce variables for terminals in mixed rules:
    • Introduce \(V_a \to a\) and \(V_b \to b\).
  2. Replace terminals in mixed rules:
    • \(aA \implies V_a A\)
    • \(bB \implies V_b B\)

Final CNF Grammar: \[S \to V_a A \mid V_b B \mid a \mid c\] \[A \to V_a A \mid a\] \[B \to V_b B \mid c\] \[C \to c\] \[V_a \to a\] \[V_b \to b\] (Note: Variable \(C\) is now unreachable from \(S\) and can be safely removed, leaving \({S, A, B, V_a, V_b}\)).

Question 8 (Execution of the CYK Parsing Algorithm)

Let \(G\) be the following grammar in Chomsky Normal Form: \[S \to AB \mid BC\] \[A \to BA \mid a\] \[B \to CC \mid b\] \[C \to AB \mid a\]

Use the Cocke-Younger-Kasami (CYK) dynamic programming algorithm to construct the triangular table \(P\) for the input string \(w = abba\) (length \(n = 4\)). Determine whether \(w \in L(G)\).

💡 View Solution

CYK Dynamic Programming Execution

Let \(w = a_1 a_2 a_3 a_4 = a b b a\). We construct table \(P[i, j]\) where \(i\) is the starting position (1 to 4) and \(j\) is the substring length (1 to 4).

Step 1: Base Case — Substrings of Length \(j = 1\)

We find all variables that directly yield \(a_i\):

  • \(i = 1 , (a_1 = a)\): Rules yielding \(a\) are \(A \to a\) and \(C \to a\). \[P = {A, C}\]
  • \(i = 2 , (a_2 = b)\): Rules yielding \(b\) is \(B \to b\). \[P = {B}\]
  • \(i = 3 , (a_3 = b)\): Rules yielding \(b\) is \(B \to b\). \[P = {B}\]
  • \(i = 4 , (a_4 = a)\): Rules yielding \(a\) are \(A \to a\) and \(C \to a\). \[P = {A, C}\]

Step 2: Substrings of Length \(j = 2\)

For \(P[i, 2]\), we evaluate splits \(k = 1\): \(P[i, 1] \times P[i+1, 1]\).

  1. \(P\) (substring \(a_1 a_2 = ab\)):

    • Split \(k=1\): \(P \times P = {A, C} \times {B} = {AB, CB}\).
    • Rules deriving \(AB\): \(S \to AB, C \to AB\). No rules derive \(CB\). \[P = {S, C}\]

  2. \(P\) (substring \(a_2 a_3 = bb\)):

    • Split \(k=1\): \(P \times P = {B} \times {B} = {BB}\).
    • No rules derive \(BB\). \[P = \emptyset\]

  3. \(P\) (substring \(a_3 a_4 = ba\)):

    • Split \(k=1\): \(P \times P = {B} \times {A, C} = {BA, BC}\).
    • Rules deriving \(BA\): \(A \to BA\). Rules deriving \(BC\): \(S \to BC\). \[P = {A, S}\]

Step 3: Substrings of Length \(j = 3\)

  1. \(P\) (substring \(a_1 a_2 a_3 = abb\)):

    • Split \(k=1\): \(P \times P = {A, C} \times \emptyset = \emptyset\).
    • Split \(k=2\): \(P \times P = {S, C} \times {B} = {SB, CB}\).
    • No rules derive \(SB\) or \(CB\). \[P = \emptyset\]

  2. \(P\) (substring \(a_2 a_3 a_4 = bba\)):

    • Split \(k=1\): \(P \times P = {B} \times {A, S} = {BA, BS}\).
    • Rules deriving \(BA\): \(A \to BA\).
    • Split \(k=2\): \(P \times P = \emptyset \times {A, C} = \emptyset\). \[P = {A}\]

Step 4: Substring of Length \(j = 4\) (Full String \(w = abba\))

We evaluate \(P\) across all split points \(k \in {1, 2, 3}\):

  • Split \(k=1\) (\(j_1=1, j_2=3\)): \(P \times P = {A, C} \times {A} = {AA, CA}\). No matching rules.
  • Split \(k=2\) (\(j_1=2, j_2=2\)): \(P \times P = {S, C} \times {A, S} = {SA, SS, CA, CS}\). No matching rules.
  • Split \(k=3\) (\(j_1=3, j_2=1\)): \(P \times P = \emptyset \times {A, C} = \emptyset\).

\[P = \emptyset\]

Conclusion:

Since \(S \notin P\), the string \(w = abba\) is NOT accepted by the grammar \(G\) (\(abba \notin L(G)\)).

Question 9 (CFL Pumping Lemma Formal Proofs)

Rigorously prove using the CFL Pumping Lemma that the following languages are not Context-Free:

  1. \(L_1 = {a^n b^n c^n \mid n \ge 0}\)
  2. \(L_2 = {w w \mid w \in {a, b}^*}\)
💡 View Solution

Part 1: Proof for \(L_1 = {a^n b^n c^n \mid n \ge 0}\)

Suppose for contradiction that \(L_1\) is context-free. Let \(m\) be the pumping length guaranteed by the CFL Pumping Lemma.

  1. Choose the string \(s = a^m b^m c^m \in L_1\). Note that \(|s| = 3m \ge m\).
  2. By the lemma, \(s\) can be written as \(s = uvxyz\) satisfying:
    • \(|vxy| \le m\)
    • \(|vy| \ge 1\)
    • \(u v^i x y^i z \in L_1\) for all \(i \ge 0\).
  3. Analyze substring \(vxy\): Since \(|vxy| \le m\), the substring \(vxy\) cannot contain all three symbol types (\(a\)’s, \(b\)’s, and \(c\)’s) simultaneously because the distance from the first \(a\) to the first \(c\) is at least \(m + 1\). Thus, \(vxy\) can contain at most two distinct symbol types (either \(a\)’s and \(b\)’s, or \(b\)’s and \(c\)’s).
  4. Pumping down (\(i = 0\) or pumping up \(i = 2\)): Consider \(s’ = u v^2 x y^2 z\).
    • Since \(vy\) contains at least one symbol (\(|vy| \ge 1\)), pumping \(vy\) increases the count of at most two symbol types.
    • The count of the third symbol type remains unchanged at \(m\).
    • Thus, in \(s’\), the counts of \(a\)’s, \(b\)’s, and \(c\)’s are no longer equal. Therefore, \(s’ \notin L_1\), contradicting the Pumping Lemma. Thus, \(L_1\) is not context-free. \(\blacksquare\)

Part 2: Proof for \(L_2 = {w w \mid w \in {a, b}^*}\)

Suppose for contradiction that \(L_2\) is context-free. Let \(m\) be the pumping length.

  1. Choose the string \(s = a^m b^m a^m b^m \in L_2\) (where \(w = a^m b^m\)). Note \(|s| = 4m \ge m\).
  2. \(s = uvxyz\) with \(|vxy| \le m\) and \(|vy| \ge 1\).
  3. Analyze position of \(vxy\): Since \(|vxy| \le m\), \(vxy\) cannot span across the boundary between the first \(b^m\) block and the second \(b^m\) block (distance \(> m\)).
    • Case 1: \(vxy\) is entirely in the first half (\(a^m b^m\)). Pumping \(i = 0\) yields \(s’ = u x z\). Pumping changes the first half of the string, but leaves the second half (\(a^m b^m\)) untouched. Thus, \(s’\) cannot be partitioned into two identical halves \(w’ w’\).
    • Case 2: \(vxy\) is entirely in the second half (\(a^m b^m\)). Similarly, pumping \(i = 0\) modifies the second half while leaving the first half (\(a^m b^m\)) untouched, so \(s’ \notin L_2\).
    • Case 3: \(vxy\) spans the midpoint boundary (\(b^m a^m\)). \(vxy\) consists of some \(b\)’s from the first half and some \(a\)’s from the second half. Pumping \(i = 0\) reduces the \(b\)’s in the first half and \(a\)’s in the second half, destroying the required structure \(w’ w’\).

In all cases, \(s’ \notin L_2\), contradicting the Pumping Lemma. Thus, \(L_2\) is not context-free. \(\blacksquare\)

Question 10 (Emptiness Decision Algorithm for CFGs)

Provide a complete, step-by-step formal algorithm to decide whether the language generated by an arbitrary Context-Free Grammar \(G = (V, T, S, P)\) is empty (\(L(G) = \emptyset\)). Prove its correctness and termination.

💡 View Solution

Formal Decision Algorithm: DECIDE_CFG_EMPTY(G)

The algorithm iteratively determines the set of all generating variables \(V_G \subseteq V\) that can derive terminal strings.

Algorithm DECIDE_CFG_EMPTY(G = (V, T, S, P)):
1. Initialize V_G = ∅  (Set of generating variables)

2. Repeat until no new variables are added to V_G:
     For each rule A -> α in P:
       If every symbol in α belongs to (T ∪ V_G):
         Add A to V_G

3. If S ∈ V_G:
     Return "L(G) ≠ ∅"  (Language is non-empty)
   Else:
     Return "L(G) = ∅"  (Language is empty)

Correctness and Termination Proof

  1. Termination: In each iteration of Step 2, either at least one new variable from the finite variable set \(V\) is added to \(V_G\), or no new variable is added. Since \(|V|\) is strictly finite, the loop can execute at most \(|V|\) times before stabilizing. Thus, the algorithm is guaranteed to terminate.

  2. Correctness:

    • Completeness: We prove by induction on derivation height \(h\) that \(A \in V_G \iff A \Rightarrow^* w\) for some \(w \in T^*\).
      • Base case (\(h=1\)): \(A \to w \in T^*\) directly adds \(A\) to \(V_G\) in iteration 1.
      • Inductive step: If \(A \to Y_1 Y_2 \dots Y_k\) where each \(Y_i \in T \cup V_G\), then each variable \(Y_i\) derives a terminal string \(w_i \in T^\). Thus, \(A \Rightarrow^ w_1 w_2 \dots w_k \in T^*\).
    • Decision: The language \(L(G)\) contains at least one terminal string if and only if the start symbol \(S\) can derive a terminal string (\(S \Rightarrow^* w \in T^*\)). This holds if and only if \(S \in V_G\) upon algorithm termination.

Thus, DECIDE_CFG_EMPTY is a sound, complete, and terminating decision procedure for \(L(G) = \emptyset\). \(\blacksquare\)
