Assignment 7: Turing Machines, Decidability, the Chomsky Hierarchy, and Computational Complexity

This assignment evaluates and deepens your understanding of Turing Machines (TMs), TM variants, the Church-Turing Thesis, decidability versus recognizability, Cantor’s diagonalization, mapping reducibility, the extended Chomsky Hierarchy, and the fundamentals of computational complexity (\(P\) vs \(NP\)), synthesizing the core principles from Michael Sipser (Parts 2 & 3) and Peter Linz (Chapters 9–12, 14).

Section A: True or False Questions

For each question, select True or False and provide a rigorous mathematical justification.

Question 1

In the standard definition of a 7-tuple Turing Machine \(M = (Q, \Sigma, \Gamma, \delta, q_0, q_{accept}, q_{reject})\), the input alphabet \(\Sigma\) is permitted to contain the blank symbol \(\sqcup\) (or \(\Box\)).

💡 View Solution

Answer: False

Justification: By formal definition (Sipser Definition 3.3, Linz Definition 9.1), the input alphabet \(\Sigma\) and tape alphabet \(\Gamma\) satisfy: \[\sqcup \in \Gamma \quad \text{and} \quad \Sigma \subseteq \Gamma \setminus {\sqcup}\] The blank symbol \(\sqcup\) is explicitly excluded from the input alphabet \(\Sigma\). This restriction is mathematically necessary so that when the machine begins computation on an input string \(w \in \Sigma^*\), the first blank symbol appearing on the tape unambiguously marks the end of the input string. If \(\sqcup\) were allowed as an input symbol, the machine could not distinguish between a blank character belonging to the input itself and the unwritten, infinite portion of the tape.

Question 2

A language \(L\) is Turing-decidable (recursive) if and only if both \(L\) and its complement \(\bar{L}\) are Turing-recognizable (recursively enumerable).

💡 View Solution

Answer: True

Justification: This is Theorem 4.22 in Sipser (Linz Theorem 11.4):

  • \((\Rightarrow)\) If \(L\) is decidable, there exists a decider \(M\) that halts on all inputs. We can recognize \(L\) using \(M\). To recognize \(\bar{L}\), we construct \(M’\) which runs \(M\) and swaps its outputs (\(q_{accept} \leftrightarrow q_{reject}\)). Since \(M\) halts on all inputs, \(M’\) also halts on all inputs, making both \(L\) and \(\bar{L}\) decidable, and thus both Turing-recognizable.
  • \((\Leftarrow)\) If \(L\) and \(\bar{L}\) are both Turing-recognizable, let \(M_1\) recognize \(L\) and \(M_2\) recognize \(\bar{L}\). We construct a decider \(D\) for \(L\) as follows: On input \(w\), \(D\) simulates \(M_1\) and \(M_2\) in parallel (interleaving step-by-step computation). Since every string \(w \in \Sigma^*\) belongs to either \(L\) or \(\bar{L}\), exactly one of \(M_1\) or \(M_2\) is guaranteed to halt and accept \(w\) in a finite number of steps. If \(M_1\) accepts, \(D\) halts and accepts; if \(M_2\) accepts, \(D\) halts and rejects. Thus, \(D\) is guaranteed to halt on all inputs, proving \(L\) is decidable.

Question 3

A multi-tape Turing machine with \(k\) tapes is strictly more powerful than a standard single-tape Turing machine, meaning there exist languages that can be recognized by a multi-tape TM but cannot be recognized by any single-tape TM.

💡 View Solution

Answer: False

Justification: By Sipser Theorem 3.13 and Linz Theorem 10.1, every multi-tape Turing machine \(M\) operating with \(k\) tapes can be simulated by an equivalent single-tape Turing machine \(S\).

  • The single-tape simulator \(S\) represents the \(k\) tapes on a single tape by using delimiter symbols \(#\) to separate tape contents and dotted symbols \(\dot{a} \in \Gamma\) to track the virtual head positions of each tape.
  • While a multi-tape TM may execute an algorithm faster (e.g., \(O(t(n))\) time on multi-tape vs \(O(t^2(n))\) time on single-tape), both models recognize the exact same class of languages (Turing-recognizable / recursively enumerable). Multi-tape storage affects time efficiency, not computability power.

Question 4

The acceptance problem language \(A_{TM} = {\langle M, w \rangle \mid M \text{ is a TM and } M \text{ accepts } w}\) is Turing-recognizable but undecidable, whereas its complement \(\bar{A}_{TM}\) is not even Turing-recognizable.

💡 View Solution

Answer: True

Justification:

  1. \(A_{TM}\) is Turing-recognizable: The Universal Turing Machine \(U\) recognizes \(A_{TM}\) by simulating \(M\) on \(w\). If \(M\) accepts \(w\), \(U\) halts and accepts.
  2. \(A_{TM}\) is undecidable: Proven by Cantor’s diagonal argument (Sipser Theorem 4.11). Assuming a decider \(H\) for \(A_{TM}\) exists leads to a self-referential machine \(D(\langle D \rangle)\) that accepts if and only if it rejects, yielding a direct contradiction.
  3. \(\bar{A}_{TM}\) is not Turing-recognizable: By Theorem 4.22, if \(\bar{A}{TM}\) were Turing-recognizable, then since \(A{TM}\) is also Turing-recognizable, \(A_{TM}\) would have to be decidable. But \(A_{TM}\) is proven undecidable, so \(\bar{A}_{TM}\) cannot be Turing-recognizable.

Question 5

Which of the following statements regarding the computational complexity classes \(P\), \(NP\), and polynomial-time reducibility (\(\le_P\)) are correct? (Select all that apply)

  • Options:
    • A) If \(A \le_P B\) and \(B \in P\), then \(A \in P\).
    • B) \(P \subseteq NP \subseteq \text{EXPTIME}\).
    • C) If any single \(NP\)-complete language is shown to belong to \(P\), then \(P = NP\).
    • D) Every language in \(P\) has a polynomial-time verifier.
💡 View Solution

Correct Options: A, B, C, D

Justification:

  • A is correct: If \(B \in P\), there exists a deterministic decider \(M_B\) running in time \(O(n^k)\). If \(A \le_P B\), there exists a reduction function \(f\) computable in time \(O(n^m)\). To decide \(A\) in polynomial time: on input \(x\), compute \(f(x)\) (takes \(O(|x|^m)\) time) and run \(M_B(f(x))\) (takes \(O(|f(x)|^k) = O(|x|^{mk})\) time). The composition runs in polynomial time, so \(A \in P\) (Sipser Theorem 7.31).
  • B is correct: By definition, \(P = \bigcup_k \text{TIME}(n^k)\) and \(NP = \bigcup_k \text{NTIME}(n^k)\). Any deterministic \(O(n^k)\) machine is a special case of a nondeterministic \(O(n^k)\) machine (\(P \subseteq NP\)). Furthermore, simulating a \(t(n)\)-time NTM deterministically requires at most \(2^{O(t(n))}\) time (Sipser Theorem 7.11), so \(NP \subseteq \text{EXPTIME} = \bigcup_k \text{TIME}(2^{n^k})\).
  • C is correct: By definition of \(NP\)-completeness, if \(L\) is \(NP\)-complete, then \(L \in NP\) and for every language \(A \in NP\), \(A \le_P L\). If \(L \in P\), then by Option A, every \(A \in NP\) must also belong to \(P\), proving \(P = NP\).
  • D is correct: A verifier \(V(x, c)\) checks if string \(c\) is a valid certificate for \(x \in L\). If \(L \in P\), a decider \(M_L\) decides \(x \in L\) in polynomial time without needing a certificate. The verifier \(V(x, c)\) simply ignores \(c\) and runs \(M_L(x)\), making \(V\) a valid polynomial-time verifier. Thus, \(P \subseteq NP\).

Question 6

Which of the following containment relationships in the Extended Chomsky Hierarchy are strictly proper (\(A \subsetneq B\))? (Select all that apply)

  • Options:
    • A) Regular Languages \(\subsetneq\) Context-Free Languages
    • B) Context-Free Languages \(\subsetneq\) Context-Sensitive Languages
    • C) Context-Sensitive Languages \(\subsetneq\) Turing-Decidable (Recursive) Languages
    • D) Turing-Decidable Languages \(\subsetneq\) Turing-Recognizable (Recursively Enumerable) Languages
💡 View Solution

Correct Options: A, B, C, D

Justification: All four inclusions are strictly proper:

  • A is strictly proper: Every regular language is context-free, but \(L = {a^n b^n \mid n \ge 0}\) is context-free and non-regular (proved via Regular Pumping Lemma).
  • B is strictly proper: Every CFL is context-sensitive, but \(L = {a^n b^n c^n \mid n \ge 1}\) is context-sensitive (accepted by an LBA) but non-context-free (proved via CFL Pumping Lemma).
  • C is strictly proper: Every CSL is decidable because sentential form lengths are bounded (\(L_{CS} \subseteq L_{DEC}\)). By a diagonalization argument over Linear Bounded Automata, there exist decidable languages that are not context-sensitive (\(L_{CS} \subsetneq L_{DEC}\)).
  • D is strictly proper: Every decidable language is Turing-recognizable (\(L_{DEC} \subseteq L_{RE}\)). The acceptance problem \(A_{TM}\) is Turing-recognizable but undecidable, proving \(L_{DEC} \subsetneq L_{RE}\).

Question 7 (Turing Machine Design and Configuration Trace)

Design a standard single-tape Turing Machine \(M = (Q, \Sigma, \Gamma, \delta, q_0, q_{accept}, q_{reject})\) over the input alphabet \(\Sigma = {0, 1, 2}\) that decides the language: \[L = {0^n 1^n 2^n \mid n \geq 1}\]

  1. Explain the high-level tape-marking strategy.
  2. Provide the formal specification of \(Q\), \(\Sigma\), \(\Gamma\), and list all transition rules in \(\delta\).
  3. Trace the complete sequence of Instantaneous Descriptions (configurations) for the input string \(w = 012\).
💡 View Solution

Step 1: Tape-Marking Strategy

To decide \(0^n 1^n 2^n\):

  1. Scan from left to right to locate the leftmost unmarked \(0\). Replace it with a cross-off marker \(X\).
  2. Continue scanning right past any remaining \(0\)’s and marked \(Y\)’s to find the leftmost unmarked \(1\). Replace it with marker \(Y\).
  3. Continue scanning right past any remaining \(1\)’s and marked \(Z\)’s to find the leftmost unmarked \(2\). Replace it with marker \(Z\).
  4. Scan leftward back to the first unmarked \(0\) (just after the rightmost \(X\)).
  5. Repeat steps 1–4 until all \(0\)’s, \(1\)’s, and \(2\)’s have been crossed off.
  6. Perform a final verification scan to ensure no residual \(0\)’s, \(1\)’s, or \(2\)’s remain on the tape, then transition to \(q_{accept}\). If any symbol mismatch occurs at any stage, transition to \(q_{reject}\).

Step 2: Formal Specification

  • \(Q = {q_0, q_1, q_2, q_3, q_4, q_{accept}, q_{reject}}\)
  • \(\Sigma = {0, 1, 2}\)
  • \(\Gamma = {0, 1, 2, X, Y, Z, \sqcup}\)
  • Start state: \(q_0\)

Transition Rules \(\delta\):

  1. Locate \(0\) and mark with \(X\):

    • \(\delta(q_0, 0) = (q_1, X, R)\)
    • \(\delta(q_0, Y) = (q_4, Y, R)\) (No more \(0\)’s left; move to verify cleanup)

  2. Seek \(1\) and mark with \(Y\):

    • \(\delta(q_1, 0) = (q_1, 0, R)\)
    • \(\delta(q_1, Y) = (q_1, Y, R)\)
    • \(\delta(q_1, 1) = (q_2, Y, R)\)

  3. Seek \(2\) and mark with \(Z\):

    • \(\delta(q_2, 1) = (q_2, 1, R)\)
    • \(\delta(q_2, Z) = (q_2, Z, R)\)
    • \(\delta(q_2, 2) = (q_3, Z, L)\)

  4. Rewind left to \(X\):

    • \(\delta(q_3, 0) = (q_3, 0, L)\)
    • \(\delta(q_3, 1) = (q_3, 1, L)\)
    • \(\delta(q_3, Y) = (q_3, Y, L)\)
    • \(\delta(q_3, Z) = (q_3, Z, L)\)
    • \(\delta(q_3, X) = (q_0, X, R)\) (Found \(X\), move right to process next \(0\))

  5. Final verification (\(q_4\)):

    • \(\delta(q_4, Y) = (q_4, Y, R)\)
    • \(\delta(q_4, Z) = (q_4, Z, R)\)
    • \(\delta(q_4, \sqcup) = (q_{accept}, \sqcup, R)\)

(All undefined state-symbol combinations transition implicitly to \(q_{reject}\))

Step 3: Configuration Trace for \(w = 012\)

We write configurations as \(u q v\) where \(q\) is the state and the head reads the first symbol of \(v\):

\[\begin{aligned} q_0 , 0 1 2 \sqcup &\vdash X , q_1 , 1 2 \sqcup && \text{(mark } 0 \to X\text{)} \ &\vdash X Y , q_2 , 2 \sqcup && \text{(mark } 1 \to Y\text{)} \ &\vdash X , q_3 , Y Z \sqcup && \text{(mark } 2 \to Z\text{, start rewind)} \ &\vdash q_3 , X Y Z \sqcup && \text{(rewind past } Y\text{)} \ &\vdash X , q_0 , Y Z \sqcup && \text{(found } X\text{, step right)} \ &\vdash X Y , q_4 , Z \sqcup && \text{(no more } 0\text{’s, enter } q_4\text{)} \ &\vdash X Y Z , q_4 , \sqcup && \text{(verify } Z\text{)} \ &\vdash X Y Z \sqcup , q_{accept} , \sqcup && \text{(read } \sqcup \implies \mathbf{ACCEPT}\text{)} \end{aligned}\]

Question 8 (Undecidability Proof via Cantor’s Diagonalization)

Rigorously prove that the Acceptance Problem \(A_{TM} = {\langle M, w \rangle \mid M \text{ is a TM that accepts } w}\) is undecidable using Cantor’s diagonalization method.

💡 View Solution

Mathematical Proof

Suppose for contradiction that \(A_{TM}\) is decidable. Then there exists a Turing Machine \(H\) that decides \(A_{TM}\): \[H(\langle M, w \rangle) = \begin{cases} q_{accept} & \text{if } M \text{ accepts } w \ q_{reject} & \text{if } M \text{ does not accept } w \text{ (rejects or loops)} \end{cases}\]

Step 1: Construct the Self-Referential Machine \(D\)

Using \(H\) as a subroutine, we build a new Turing Machine \(D\) that takes the encoding of a Turing Machine \(\langle M \rangle\) as its input:

\[D = \text{“On input } \langle M \rangle \text{ where } M \text{ is a TM:}\]

  1. Run \(H\) on input \(\langle M, \langle M \rangle \rangle\).
  2. Output the opposite of what \(H\) outputs:
    • If \(H\) accepts, \(D\) rejects.
    • If \(H\) rejects, \(D\) accepts.”

Mathematically, \(D\)’s behavior is: \[D(\langle M \rangle) = \begin{cases} \text{accept} & \text{if } M \text{ does not accept } \langle M \rangle \ \text{reject} & \text{if } M \text{ accepts } \langle M \rangle \end{cases}\]

Step 2: Execute \(D\) on its own description \(\langle D \rangle\)

Now we run machine \(D\) with its own encoding \(\langle D \rangle\) as input: \[D(\langle D \rangle) = \begin{cases} \text{accept} & \text{if } D \text{ does not accept } \langle D \rangle \ \text{reject} & \text{if } D \text{ accepts } \langle D \rangle \end{cases}\]

  • Case 1: If \(D\) accepts \(\langle D \rangle\), then by definition of \(D\)’s construction, \(H(\langle D, \langle D \rangle \rangle)\) must accept, causing \(D\) to reject \(\langle D \rangle\). Contradiction!
  • Case 2: If \(D\) rejects \(\langle D \rangle\), then \(H(\langle D, \langle D \rangle \rangle)\) must reject, causing \(D\) to accept \(\langle D \rangle\). Contradiction!

In both cases, we reach a logical impossibility: \(D\) accepts \(\langle D \rangle \iff D\) does not accept \(\langle D \rangle\).

Step 3: Connection to Diagonalization and Countability

This contradiction stems directly from Cantor’s Diagonalization argument:

  • The set of all Turing machines is countably infinite (each TM \(M_i\) has a finite description string that can be ordered lexicographically: \(M_1, M_2, M_3, \dots\)).
  • The set of all languages over \(\Sigma\) is uncountably infinite (equal to the power set \(2^{\Sigma^*}\)).
  • If we construct an infinite grid where row \(i\) represents \(M_i\) and column \(j\) represents input \(w_j\), entry \((i, j)\) indicates whether \(M_i\) accepts \(w_j\). Machine \(D\) constructs the inverted diagonal language: \[L_D = { w_i \mid M_i \text{ does not accept } w_i }\] Because \(L_D\) differs from every TM \(M_i\) on the \(i\)-th diagonal element, no TM in the enumerated list can recognize \(L_D\). Thus, \(H\) cannot exist, proving \(A_{TM}\) is undecidable. \(\blacksquare\)

Question 9 (Mapping Reducibility & The Halting Problem)

Prove that the Halting Problem \(HALT_{TM} = {\langle M, w \rangle \mid M \text{ is a TM that halts on input } w}\) is undecidable by constructing a mapping reduction \(A_{TM} \le_m HALT_{TM}\).

💡 View Solution

Mathematical Proof

To prove \(HALT_{TM}\) is undecidable via mapping reduction \(A_{TM} \le_m HALT_{TM}\), we must construct a computable function \(f: \Sigma^* \to \Sigma^*\) such that: \[\langle M, w \rangle \in A_{TM} \iff f(\langle M, w \rangle) \in HALT_{TM}\]

Step 1: Construction of the Reduction Function \(f\)

Let \(F\) be a computable reduction machine that computes \(f(\langle M, w \rangle) = \langle M’, w \rangle\):

\[F = \text{“On input } \langle M, w \rangle:\]

  1. Construct the description of a new Turing Machine \(M’\): \[M’ = \text{‘On input } x:\]
    1. Run \(M\) on input \(x\).
    2. If \(M\) accepts, accept.
    3. If \(M\) rejects, enter an infinite loop.’
  2. Output \(\langle M’, w \rangle\).”

Step 2: Proof of Correctness

We verify the bi-conditional requirement \(\langle M, w \rangle \in A_{TM} \iff \langle M’, w \rangle \in HALT_{TM}\):

  • \((\Rightarrow)\) Suppose \(\langle M, w \rangle \in A_{TM}\): This means \(M\) accepts \(w\). When \(M’\) runs on \(w\), step 1 simulates \(M(w)\), which accepts. Step 2 causes \(M’\) to accept and halt. Thus, \(M’\) halts on \(w\), meaning \(\langle M’, w \rangle \in HALT_{TM}\).

  • \((\Leftarrow)\) Suppose \(\langle M, w \rangle \notin A_{TM}\): This means \(M\) does not accept \(w\) (either \(M\) rejects \(w\) or \(M\) loops infinitely on \(w\)).

    • If \(M\) rejects \(w\), \(M’\) reaches step 3 and enters an infinite loop, so \(M’\) does not halt on \(w\).
    • If \(M\) loops infinitely on \(w\), \(M’\) gets stuck in step 1 simulating \(M\), so \(M’\) does not halt on \(w\). In both cases, \(M’\) does not halt on \(w\), meaning \(\langle M’, w \rangle \notin HALT_{TM}\).

Thus, \(f(\langle M, w \rangle) = \langle M’, w \rangle\) is a valid mapping reduction \(A_{TM} \le_m HALT_{TM}\).

Step 3: Decidability Implication

By Corollary 5.23 (Sipser), if \(A \le_m B\) and \(A\) is undecidable, then \(B\) must be undecidable. Since \(A_{TM}\) is proven undecidable, \(HALT_{TM}\) is undecidable. \(\blacksquare\)

Question 10 (Linear Bounded Automata & Configuration Counting)

A Linear Bounded Automaton (LBA) is a nondeterministic Turing machine whose read-write head cannot move beyond the portion of the tape occupied by the input (enforced by left boundary [ and right boundary ]).

  1. Let \(M\) be an LBA with \(|Q| = q\) states and tape alphabet \(|\Gamma| = g\). For an input string \(w\) of length \(n\), prove that the maximum number of distinct configurations of \(M\) on \(w\) is given by: \[N_{config} = q \cdot n \cdot g^n\]
  2. Using this configuration bound, prove that the LBA Acceptance Problem \(A_{LBA} = {\langle M, w \rangle \mid M \text{ is an LBA that accepts } w}\) is decidable.
💡 View Solution

Part 1: Configuration Counting Proof

A configuration of a Turing Machine captures three components: the state, the head position, and the current tape contents. For an LBA on an input string of length \(n\):

  1. Control State: The machine can be in any of its \(|Q| = q\) internal states.
  2. Head Position: The read-write head is restricted to the \(n\) tape cells containing the input (between the boundary markers [ and ]). Thus, there are exactly \(n\) possible head positions.
  3. Tape Contents: The tape contains \(n\) cells, each holding a symbol from the tape alphabet \(\Gamma\) of size \(|\Gamma| = g\). The total number of distinct tape symbol combinations across \(n\) cells is \(g^n\).

The maximum number of distinct configurations is the product of these three independent choices: \[N_{config} = \text{(States)} \times \text{(Head Positions)} \times \text{(Tape Patterns)} = q \cdot n \cdot g^n \quad \blacksquare\]

Part 2: Proof that \(A_{LBA}\) is Decidable

We construct a deterministic decider \(D\) for \(A_{LBA} = {\langle M, w \rangle \mid M \text{ is an LBA that accepts } w}\):

\[D = \text{“On input } \langle M, w \rangle \text{ where } M \text{ is an LBA and } w \text{ is a string:}\]

  1. Calculate \(N = q \cdot n \cdot g^n\), the maximum number of distinct configurations for \(M\) on \(w\), where \(n = |w|\), \(q = |Q_M|\), and \(g = |\Gamma_M|\).
  2. Simulate \(M\) on input \(w\) for at most \(N\) steps.
  3. If \(M\) enters \(q_{accept}\) within \(N\) steps, accept.
  4. If \(M\) enters \(q_{reject}\) or if \(M\) executes \(N + 1\) steps without halting, reject.”

Correctness Justification

  • If \(M\) accepts \(w\), it must reach \(q_{accept}\) in some number of steps. If it takes more than \(N\) steps without reaching \(q_{accept}\), then by the Pigeonhole Principle, \(M\) must have visited at least one configuration twice during its computation (\(N + 1\) steps vs \(N\) unique configurations).
  • Since \(M\) is deterministic (or following a specific branch of choice tree), repeating a configuration means \(M\) has entered an infinite loop and will never halt or accept.
  • Therefore, if \(M\) has not accepted within \(N\) steps, \(D\) can safely terminate simulation and reject, guaranteeing that \(D\) always halts on all inputs.
  • Thus, \(A_{LBA}\) is decidable. \(\blacksquare\)
