Question 1

If a context-free grammar $G$ is unambiguous, then for every string $w \in L(G)$, there exists exactly one leftmost derivation and exactly one rightmost derivation, and both derivations correspond to the same unique parse tree.

💡 View Solution

Answer: True

Justification: By definition, a string $w$ is derived ambiguously in a CFG if it has two or more distinct leftmost derivations (or equivalently, two or more distinct rightmost derivations).

  • A parse tree (or derivation tree) represents the hierarchical syntactic structure of a derivation, independent of the order in which variables are replaced.
  • There exists a strict bijection (1-to-1 correspondence) between the set of all parse trees for $w$ and the set of all leftmost derivations for $w$.
  • Therefore, if $G$ is unambiguous, $w$ has exactly one parse tree. Since each parse tree corresponds to exactly one leftmost derivation and exactly one rightmost derivation, both must be unique and map to that same tree.

Question 2

The family of regular languages is a proper subset of context-free languages. Consequently, every right-linear grammar is context-free, but not every context-free grammar is regular.

💡 View Solution

Answer: True

Justification: By definition, a regular grammar must be right-linear ($A \to wB$ or $A \to w$) or left-linear ($A \to Bw$ or $A \to w$). A context-free grammar has the sole restriction that the left-hand side of any production rule must be a single variable.

  • Since the left-hand side of every regular grammar rule is a single variable, all regular grammars are context-free.
  • Conversely, many context-free grammars are not regular. For example, the linear grammar $S \to aSb \mid \varepsilon$ generates the non-regular language $\{a^n b^n \mid n \geq 0\}$. The variable $S$ is nested between terminals $a$ and $b$, which violates the right-linear and left-linear constraints of regular grammars.

Question 3

If a context-free language $L$ is inherently ambiguous, then there exists at least one unambiguous CFG $G$ such that $L(G) = L$.

💡 View Solution

Answer: False

Justification: By definition, a context-free language $L$ is inherently ambiguous if and only if every context-free grammar $G$ that generates $L$ is ambiguous. If there existed even one unambiguous grammar $G$ such that $L(G) = L$, then by definition $L$ would not be inherently ambiguous.

Question 4

A linear grammar is a context-free grammar where every production rule has at most one variable on its right-hand side. Every linear grammar is guaranteed to generate a regular language.

💡 View Solution

Answer: False

Justification: While the definition of a linear grammar is correct (every production has at most one variable on the right-hand side), it is not true that every linear grammar generates a regular language.

  • The grammar $G$ with rules $S \to aSb \mid \varepsilon$ is linear because the right-hand side of $aSb$ contains exactly one variable ($S$).
  • However, $L(G) = \{a^n b^n \mid n \geq 0\}$, which is a classic non-regular context-free language. Thus, linear grammars can generate non-regular languages.

Question 5

Let $G = (V, T, S, P)$ be a context-free grammar. Which of the following statements regarding derivations, sentential forms, and parse trees are correct? (Select all that apply)

  • Options:
    • A) A sentential form is any string $w \in (V \cup T)^*$ such that $S \Rightarrow^* w$.
    • B) The yield of any partial derivation tree with root $S$ is a sentential form of $G$.
    • C) If a complete derivation tree has only terminals at its leaves, its yield is a sentence in $L(G)$.
    • D) A single parse tree can correspond to multiple distinct leftmost derivations.
💡 View Solution

Correct Options: A, B, C

Justification:

  • A is correct: By definition, a sentential form is any string of variables and terminals derivable from the start symbol $S$ in zero or more steps.
  • B is correct: Linz Theorem 5.1 establishes that the yield of any partial derivation tree rooted at $S$ is a sentential form of $G$.
  • C is correct: A complete derivation tree rooted at $S$ where all leaves are terminals (or $\varepsilon$) represents a finished derivation containing no variables. The yield of this tree is a terminal string $w \in \Sigma^*$, which is a sentence in $L(G)$.
  • D is incorrect: There is a strict, unique 1-to-1 correspondence between a parse tree and its corresponding leftmost derivation. A parse tree cannot correspond to more than one leftmost derivation.

Question 6

Consider the grammar $G$ over $\Sigma = \{a, b\}$ with production rules:

$$S \to aSb \mid abS \mid \varepsilon$$

Which of the following statements are correct? (Select all that apply)

  • Options:
    • A) $G$ is an ambiguous grammar because the string $ab$ has two distinct parse trees.
    • B) $G$ is unambiguous because it generates the regular language $(ab)^*$.
    • C) The leftmost derivation $S \Rightarrow aSb \Rightarrow ab$ and the leftmost derivation $S \Rightarrow abS \Rightarrow ab$ represent different syntactic structures for $ab$.
    • D) $L(G) = \{a^n b^n \mid n \geq 0\}$.
💡 View Solution

Correct Options: A, C

Justification:

  • A and C are correct: To prove $G$ is ambiguous, we must show that at least one string has two distinct leftmost derivations (or parse trees). Let’s test the string $w = ab$:
    • Derivation 1: $S \Rightarrow aSb \Rightarrow ab$ (using $S \to aSb$ then $S \to \varepsilon$).
    • Derivation 2: $S \Rightarrow abS \Rightarrow ab$ (using $S \to abS$ then $S \to \varepsilon$). Since $ab$ has two distinct leftmost derivations, the grammar is ambiguous, and these derivations correspond to two different parse trees.
  • B is incorrect: Since the grammar is proven ambiguous in Option A, it cannot be unambiguous.
  • D is incorrect: The grammar can generate strings that do not belong to $\{a^n b^n\}$. For example, using the rule $S \to abS$ twice: $$S \Rightarrow abS \Rightarrow ababS \Rightarrow abab$$ The string $abab$ has $n_a = n_b = 2$, but it is not of the form $a^2 b^2$ (which is $aabb$). Thus, $L(G) \neq \{a^n b^n\}$.

Question 7 (CFG Design and Analysis)

Design a context-free grammar $G$ over $\Sigma = \{a, b\}$ that generates the language:

$$L = \{w \in \{a,b\}^* \mid n_a(w) = 2n_b(w) + 1\}$$
  1. Provide the formal 4-tuple description $G = (V, \Sigma, R, S)$.
  2. Show the leftmost derivation for the string $aaab$.
  3. Draw the corresponding parse tree for $aaab$.
💡 View Solution

Part 1: Grammar Design

Every string $w \in L$ must contain exactly one extra $a$ in addition to having twice as many $a$’s as $b$’s.

Let $T$ be a variable that generates strings with exactly twice as many $a$’s as $b$’s ($n_a = 2n_b$). We can define $T$ recursively:

  • For every $b$ we generate, we must generate two $a$’s. These $a$’s can appear in any position relative to $b$.
  • Thus, the base rules for $T$ to balance one $b$ and two $a$’s are: $$T \to aTaTb \mid aTbTa \mid bTaTa \mid TT \mid \varepsilon$$

To get exactly one extra $a$, we can split the string into a portion before the extra $a$ (which must satisfy $n_a = 2n_b$) and a portion after the extra $a$ (which must also satisfy $n_a = 2n_b$). Therefore, our start variable $S$ is:

$$S \to T a T$$

Formal 4-tuple:

$$G = (V, \Sigma, R, S)$$
  • $V = \{S, T\}$
  • $\Sigma = \{a, b\}$
  • The start variable is $S$.
  • The production rules $R$ are: $$S \to T a T$$ $$T \to aTaTb \mid aTbTa \mid bTaTa \mid TT \mid \varepsilon$$

Part 2: Leftmost Derivation of $aaab$

The string $aaab$ has $n_a = 3$ and $n_b = 1$, which satisfies $3 = 2(1) + 1$. Let’s derive it:

$$\begin{aligned} S &\Rightarrow T a T && \text{(using } S \to T a T\text{)} \\ &\Rightarrow (aTaTb) a T && \text{(using } T \to aTaTb \text{ on the first } T\text{)} \\ &\Rightarrow a (\varepsilon) a T b a T && \text{(using } T \to \varepsilon \text{ on the leftmost } T\text{)} \\ &\Rightarrow aaTb a T && \text{(simplifying)} \\ &\Rightarrow aa(\varepsilon) b a T && \text{(using } T \to \varepsilon\text{)} \\ &\Rightarrow aa b a T && \text{(simplifying)} \\ &\Rightarrow aa b a (\varepsilon) && \text{(using } T \to \varepsilon \text{ on the last } T\text{)} \\ &\Rightarrow aaba && \text{(Wait! This is } aaba \text{, which is not } aaab\text{! Let's try again.)} \end{aligned}$$

Let’s do the correct leftmost derivation for $aaab$:

$$\begin{aligned} S &\Rightarrow T a T \\ &\Rightarrow (aTbTa) a T && \text{(using } T \to aTbTa \text{ on the first } T\text{)} \\ &\Rightarrow a (\varepsilon) b T a a T && \text{(using } T \to \varepsilon \text{ on the leftmost } T\text{)} \\ &\Rightarrow ab T a a T \\ &\Rightarrow ab (\varepsilon) a a T && \text{(using } T \to \varepsilon\text{)} \\ &\Rightarrow abaa T \\ &\Rightarrow abaa (\varepsilon) && \text{(using } T \to \varepsilon\text{)} \\ &\Rightarrow abaa && \text{(This is } abaa\text{, which is in the language. Let's find } aaab\text{.)} \end{aligned}$$

Let’s derive $aaab$ using $S \to T a T$:

$$\begin{aligned} S &\Rightarrow T a T \\ &\Rightarrow \varepsilon a T && \text{(using } T \to \varepsilon \text{ on the first } T\text{)} \\ &\Rightarrow a T \\ &\Rightarrow a (aTaTb) && \text{(using } T \to aTaTb \text{ on the remaining } T\text{)} \\ &\Rightarrow aa (\varepsilon) a T b && \text{(using } T \to \varepsilon \text{ on the leftmost } T\text{)} \\ &\Rightarrow aaa T b \\ &\Rightarrow aaa (\varepsilon) b && \text{(using } T \to \varepsilon\text{)} \\ &\Rightarrow aaab && \text{(Successfully derived!)} \end{aligned}$$

  1. Show two distinct leftmost derivations.
  2. Show their corresponding rightmost derivations.

Question 9 (The Concept of Inherent Ambiguity)

The context-free language:

$$L = \{a^i b^j c^k \mid i = j \text{ or } j = k \quad \text{where } i, j, k \geq 1\}$$

is inherently ambiguous.

  1. Explain intuitively why any context-free grammar designed to generate $L$ must be ambiguous.
  2. Identify a specific subset of strings in $L$ that forces ambiguity, and describe how these strings are parsed under two different syntactic interpretations.
💡 View Solution

Part 1: Intuitive Analysis of Inherent Ambiguity

To generate the language $L$, any CFG must combine two independent matching mechanisms:

  1. Branch 1 ($i = j$): A subgrammar $G_{ab}$ that matches the number of $a$’s and $b$’s ($a^n b^n$), followed by an arbitrary number of $c$’s ($c^k$).
  2. Branch 2 ($j = k$): A subgrammar $G_{bc}$ that generates an arbitrary number of $a$’s ($a^i$), followed by a matched number of $b$’s and $c$’s ($b^m c^m$).

The combined grammar must have a rule like $S \to S_{ab} \mid S_{bc}$ to generate the union.

  • Because the two matching rules are independent, the grammar cannot communicate across the branches to “coordinate” when both conditions are met.
  • Therefore, any string that satisfies both conditions simultaneously will have a valid derivation through $S_{ab}$ and another completely independent derivation through $S_{bc}$.

Part 2: The Overlapping Subset of Strings

The subset of strings that forces ambiguity consists of strings where all three symbol counts are equal:

$$L_{overlap} = \{a^n b^n c^n \mid n \geq 1\}$$

Let’s consider the string $s = a^2 b^2 c^2 \in L$.

  • Interpretation 1 (Parsed via Branch 1: $i=j$): The parse tree structures the string as $(a^2 b^2) c^2$. The grammar pairs the two $a$’s with the two $b$’s first, treating the $c^2$ as an independent tail block. This tree highlights the relationship: $$n_a = n_b$$
  • Interpretation 2 (Parsed via Branch 2: $j=k$): The parse tree structures the string as $a^2 (b^2 c^2)$. The grammar treats $a^2$ as an independent prefix block, and pairs the two $b$’s with the two $c$’s. This tree highlights the relationship: $$n_b = n_c$$

Because both derivations are mathematically valid for any grammar $G$ that recognizes $L$, the string $a^2 b^2 c^2$ must have at least two distinct parse trees in any such grammar. Thus, the language is inherently ambiguous.

Question 10 (Mathematical Induction Proof on Tree Height)

A context-free grammar $G = (V, T, S, P)$ is in Chomsky Normal Form (CNF) if all production rules are of the form $A \to BC$ or $A \to a$, where $A, B, C \in V$ and $a \in T$.

Prove by mathematical induction on the height $h \geq 1$ of a parse tree that the length of its yield, denoted $|w|$, is at most $2^{h-1}$.

💡 View Solution

Mathematical Formulation

Let $P(h)$ be the statement: “Any parse tree of height $h \geq 1$ in a Chomsky Normal Form grammar has a yield $w \in T^*$ of length $|w| \leq 2^{h-1}$.”

Basis Step

Let $h = 1$.

  • A parse tree of height 1 must consist of a root variable $S$ and a single leaf node.
  • Since the grammar is in CNF, the only production rule that can generate a tree of height 1 is of the form $S \to a$, where $a \in T$.
  • The yield is $w = a$, which has length $|w| = 1$.
  • Since $2^{h-1} = 2^{1-1} = 2^0 = 1$, we have: $$|w| \leq 2^{h-1} \implies 1 \leq 1$$ The basis step holds.

Inductive Hypothesis

Assume that for any parse tree of height $k$ where $1 \leq k \leq h$, the yield $w$ satisfies:

$$|w| \leq 2^{k-1}$$

Inductive Step

We must show that a parse tree of height $h + 1$ has a yield $w$ of length $|w| \leq 2^h$.

Let $T_S$ be a parse tree of height $h + 1$ rooted at the start symbol $S$. Since $h \geq 1$, the height of $T_S$ is at least 2.

  • Therefore, the first production rule applied at the root must be a variable-branching rule of the form: $$S \to AB \quad \text{where } A, B \in V$$
  • This splits the tree $T_S$ into two subtrees: $T_A$ (rooted at $A$) and $T_B$ (rooted at $B$).
  • Let the height of $T_A$ be $h_1$ and the height of $T_B$ be $h_2$. Since the overall height of $T_S$ is $h + 1$, the heights of the subtrees must satisfy: $$h_1 \leq h \quad \text{and} \quad h_2 \leq h$$ with at least one of them being exactly equal to $h$.
  • Let $w_A$ be the yield of $T_A$ and $w_B$ be the yield of $T_B$. The total yield of $T_S$ is the concatenation of the two yields: $w = w_A w_B$, meaning: $$|w| = |w_A| + |w_B|$$
  • Since $h_1 \leq h$ and $h_2 \leq h$, we can apply our Inductive Hypothesis to both subtrees: $$|w_A| \leq 2^{h_1-1} \leq 2^{h-1}$$ $$|w_B| \leq 2^{h_2-1} \leq 2^{h-1}$$
  • Summing these inequalities: $$|w| = |w_A| + |w_B| \leq 2^{h-1} + 2^{h-1} = 2 \cdot 2^{h-1} = 2^h$$ This completes the inductive step, showing that $P(h) \implies P(h+1)$.

By the principle of mathematical induction, the theorem holds for all parse trees of height $h \geq 1$ in any Chomsky Normal Form grammar. $\blacksquare$
