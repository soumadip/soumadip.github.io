Fun Games

A curated collection of useful reference materials, tools, and links related to Fun Games.

🔗
Vim Adventures
An interactive RPG game played inside your browser that teaches you vim keyboard shortcuts and navigation, which are vital for terminal-based system editing.
🔗
Sad Servers
Like an escape room for Linux. It gives you a real, broken Linux server in your browser, and you have to use terminal commands to diagnose and fix the system issue.
🔗
Bandit - Unix/Linux basics by the OverTheWire community
A text-based security and systems wargame. It walks you from absolute beginner terminal usage to advanced file permissions, networking, and data manipulation.
