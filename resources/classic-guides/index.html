Classic Guides

A curated collection of useful reference materials, tools, and links related to Classic Guides.

🔗
Operating Systems: Three Easy Pieces
Remzi H. Arpaci-Dusseau and Andrea C. Arpaci-Dusseau (University of Wisconsin-Madison)
🔗
The Missing Semester of Your CS Education
A free course by MIT that teaches you how to master the command line, use powerful text editors, build automated scripts, configure SSH, and properly use version control—the foundational "missing" skills of systems work.
🔗
Brendan Gregg's Performance Tools
The definitive roadmap for understanding system performance. His famous diagrams map exactly which Linux terminal command (like top, vmstat, iostat, or perf) to use depending on which hardware component you want to investigate.
🔗
Beej's Guide to Network Programming
Absolute gold standard guide for anyone learning how to write internet applications in C.
🔗
Beej's Guide to C Programming
Systems programming requires a strong foundation in C, and this guide is designed for people who want to truly understand the language without the academic stiffness.
🔗
Beej's Guide to Interprocess Communication (IPC)
Once you know how to write a basic program, this guide teaches you how different programs on the same computer talk to one another.
🔗
Beej's Guide to GIT
A shorter, highly practical guide to version control.
🔗
Teach Yourself Computer Science
If you’re a self-taught engineer or bootcamp grad, you owe it to yourself to learn computer science.
🔗
Crafting Interpreters
Highly accessible guide to building your own programming language from scratch.
